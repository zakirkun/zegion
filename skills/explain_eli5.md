# Explain Simply (ELI5)

Use this when the user asks to explain a complex topic, or says "explain like I'm five / new to this".

## Procedure

1. Identify the single core idea behind the topic.
2. Build a concrete, everyday analogy for it.
3. Layer in one level of real detail at a time, checking it stays intuitive.

## Rules

- No jargon on first pass; introduce terms only after the intuition lands, then name them.
- Short sentences. One idea per sentence.
- Use a familiar example (cooking, queues, lending a book) over abstract definitions.

## Output

- The analogy first.
- A "the real terms" section mapping the analogy to the actual concepts.
- One common misconception corrected.
- Offer to go deeper if wanted.
