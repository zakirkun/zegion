# Decision Analysis

Use this when the user faces a choice between options.

## Procedure

1. List the options and the criteria that actually matter to the user.
2. Weight criteria by importance (ask if unclear).
3. Score each option per criterion; be honest about uncertainty.
4. Present the trade-offs, not just a winner.

## Output format

- A comparison table: criteria × options.
- **Recommendation** with the deciding factor.
- **When to choose otherwise** — the condition that would flip the decision.
- Biggest risk of the recommended option and how to mitigate it.

## Rules

- Don't manufacture false balance; if one option clearly wins, say so.
- Surface hidden costs (lock-in, maintenance, switching cost).
- Record the decision rationale with `memory_store` if significant.
