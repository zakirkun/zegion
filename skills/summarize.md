# Summarize Text

When the user asks for a summary, follow this procedure:

1. Identify the target text (provided inline, via file, or via URL).
2. Read it fully before summarizing.
3. Produce a summary with:
   - **TL;DR** — one sentence.
   - **Key points** — 3-7 bullets.
   - **Details** — a short paragraph if the content warrants it.
4. Preserve numbers, names, and dates exactly. Do not invent facts.
5. If the text is longer than fits comfortably, summarize section by section,
   then combine into a final summary.

Keep the user's language (English or Indonesian) for the output.
