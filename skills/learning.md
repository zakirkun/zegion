# Learning Capture

Use this to decide what belongs in long-term memory. Zegion's memory is precious — be selective.

## What to store (use `memory_store`)

- Stable user preferences (editor, language, units, working hours).
- Durable facts about the user's projects, environment, and constraints.
- Explicitly stated goals and deadlines.
- Corrections the user made more than once (turn them into rules).

## What NOT to store

- One-off questions, small talk, transient state.
- Anything already obvious from context.
- Secrets, credentials, or sensitive personal data.

## How to store

- One concise, self-contained sentence per memory. Include the "why" if non-obvious.
- Set importance: 0.9 for explicit rules, 0.7 for preferences, 0.5 for context.
- Before storing, check `memory_recall` to avoid duplicates; update rather than repeat.
