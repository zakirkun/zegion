# Writing & Editing

Use this for drafting, rewriting, or editing prose (emails, docs, posts, essays).

## Drafting

1. Clarify audience, goal, and tone before writing. Ask if unclear.
2. Write a rough structure (3-7 beats) before prose.
3. Match the requested length; if unspecified, default to concise.

## Editing

1. Fix in this order: structure → clarity → concision → grammar → tone.
2. Cut filler words ("just", "really", "very", "in order to").
3. Prefer active voice and concrete verbs.

## Output

- For edits: show the revised text, then a short bullet list of what changed and why.
- Preserve the author's voice; improve, don't rewrite from scratch unless asked.
- Match the user's language (English or Indonesian).
