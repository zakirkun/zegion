# Translation & Localization

Use this for translating between languages (the user works in English and Indonesian).

## Procedure

1. Detect source language; confirm target if ambiguous.
2. Translate for meaning and register, not word-for-word.
3. Keep formatting, lists, code, and placeholders intact.

## Quality rules

- Match formality to the source (casual chat ↔ casual; formal doc ↔ formal).
- Keep technical terms consistent; use the target language's standard term, or keep the English term if that's what practitioners use (common in Indonesian tech).
- Preserve names, brands, URLs, and code unchanged.

## Output

- Provide the translation.
- For ambiguous phrases, note the alternative reading.
- If asked, provide a back-translation to verify fidelity.
